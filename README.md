# Keefy TV — Android فقط

تطبيق IPTV مبني باستخدام Flutter ومخصص لأجهزة **Android فقط** (الهواتف وأجهزة Android TV).

لا يتم إنشاء أو بناء نسخة iOS أو iPhone أو iPad. عملية GitHub Actions تنشئ منصة Android وحدها وتنتج ملف APK.

## مصادر التشغيل
- M3U / M3U8
- Xtream Codes
- Stalker Portal

## بناء APK
من تبويب Actions شغّل **Build Keefy TV for Android only**. عند نجاح البناء سيظهر ملف APK ضمن Artifacts باسم `keefy-tv-release-apk`.
